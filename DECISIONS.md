- **`fitspatrick` treated as categorical** (6 Fitzpatrick types, ordinal but few levels). `age`, `diameter_1`, `diameter_2` are continuous: standardised with train mean/std, mean-imputed (=0 after standardisation) plus an explicit missing flag.
- **Index 0 has a learnable embedding** (not `padding_idx`), so the model can learn what "missing" means per field; it is never shared with any observed value.
- **Image-global vector = mean of the 49 projected 256-d tokens** (after the 1x1 conv), shared by all four models through one `ImageEncoder`. This makes `fused = image_global + g*attn_out` dimensionally exact and lets the gate-zero test compare against a real `ImageOnly` model with copied weights.
- **ImputeFusion = LateFusion architecture with mean/mode imputation and no indicators.** Missing categorical -> train mode index (inside the model, from buffers), missing continuous -> train mean, missing flags ignored. Same encoder width, same head, same training recipe — the only difference from LateFusion is missingness awareness.
- **Modality dropout is applied to all three metadata models** (late, impute, gated), identically — NEEDS HUMAN REVIEW. Fair-comparison choice; a "gated without modality dropout" ablation is recommended later.
- **[SUPERSEDED by the WP10 entry below]** **Inference masking definition:** for rate r, each sample gets exactly `floor(r*F + 0.5)` of its F=21 metadata fields masked, drawn uniformly from all fields (`eval.mask_pool: all`), keyed by (mask_seed, crc32(img_id)) so it is independent of batch order/size. Already-missing fields can be drawn, so the *effective* missingness is also reported — NEEDS HUMAN REVIEW (alternative `mask_pool: observed` is implemented).
- **"Minority-pair augmentation" interpreted as** oversampling intact (image, metadata) pairs of rare classes up to 50% of the largest class (max 4x), each copy getting independent random image augmentation; no synthetic tabular rows (no SMOTE). Class weights for the focal loss are computed from the effective (post-oversampling) training distribution so the two corrections do not double-count — NEEDS HUMAN REVIEW.
- **Split algorithm:** union-find over patient_id and lesion_id gives groups; each group's stratum is its rarest class; within each stratum groups are shuffled (seeded) and assigned to train/val/test by cumulative image count. Split is saved to `splits/split_seed{N}.csv` and committed.
- **Bootstrap CIs are patient-clustered** (resample patients, not images), because images of one patient are correlated — NEEDS HUMAN REVIEW (set `eval.bootstrap_group: null` for per-image).
- **Malignant recall reported two ways:** `malignant_recall_macro` (mean recall of BCC/MEL/SCC) and `malignant_sensitivity` (malignant images predicted as any malignant class).
- **AMP only on CUDA**; CPU runs in fp32.
- **numpy is range-pinned** (`>=1.26,<3`) rather than exact, so pip does not swap the numpy Kaggle's preinstalled torch was built against.
- **Split algorithm (revised):** sklearn `StratifiedGroupKFold(n_splits=20, shuffle=True, random_state=seed)` on the union-find groups, then whole folds go 14/3/3 to train/val/test. Two simpler greedy versions were tried first and rejected: a per-stratum cumulative split put only 4 MEL images in val, and a largest-group-first fill skewed the class mix (BCC 80% train) and left val/test with mostly single-image patients. Seed-42 result: train/val/test = 1589/364/345 images (69.1/15.8/15.0%), MEL = 39/6/7. **MEL has only 6-7 images in val/test** — per-class MEL recall will be very noisy; report CIs and do not over-interpret it.
- **Synthetic fixture uses 60/20/20 with 5 folds** (≈120 patients cannot fill 20 stratified folds with every class in every split). Real data uses the configured 70/15/15.

## 2026-10-12 — Data findings that need the team's attention

- **lesion_id is not globally unique:** 1,641 lesion ids but 1,891 (patient, lesion) pairs; 250 lesion ids appear under two different patient ids (for example lesion 1867 under PAT_995 and PAT_1545). These might be duplicate patient registrations or id reuse. They are merged into one group (union-find), giving 1,132 groups, so no patient or lesion id crosses splits. NEEDS HUMAN REVIEW (check with the dataset authors or the companion repo).
- **Missingness is a label shortcut in PAD-UFES-20 — NEEDS HUMAN REVIEW (most important item).** 13 fields (smoke, drink, background_father/mother, pesticide, gender, skin/cancer history, piped water, sewage, fitspatrick, diameter_1/2) are missing together in 804 rows (35%), and **all 804 are benign (ACK 447, NEV 169, SEK 188)**. Every BCC/MEL/SCC row has the full questionnaire. So a missingness-aware model can learn "questionnaire missing => benign", which inflates its clean score and can make malignant cases look benign once inference-time masking removes their fields. What was implemented tonight (no choice made for the team): (1) `results/missingness_by_class.csv` documents it; (2) evaluation reports every metric on `all` and on the `complete_metadata` subset (rows with at most 2 missing fields, n=1,445), where the masking sweep is a clean, controlled experiment; (3) `data.train_subset: complete_metadata` lets the team train only on complete rows. Recommended: make the complete-metadata subset the primary setting for the missingness sweep, and say so in the paper.
- **Config hash excludes `paths`, `runtime` and `seed`**, so every seed of one experiment, on any machine, shares a hash; the run name (`{model}_s{seed}_{hash8}`) carries the seed.
- **Checkpoints are loaded with `torch.load(weights_only=False)`** because they also hold RNG states and the preprocessor; only ever load checkpoints this project produced.
- **Focal loss is normalised by the sum of the class weights** (like weighted cross-entropy), so gamma=0 equals `F.cross_entropy(weight=w)` exactly (tested).
- **Gate log** (`results/gate_log.csv`, gated model only) records per epoch: train gate mean/std, val gate mean/std, and the val gate mean with ALL metadata masked. A gate that does not drop when metadata is removed is evidence against the paper's claim; a std < 1e-3 or a mean outside (0.02, 0.98) prints a collapse warning.
- **Rate 0 is evaluated once** (mask seed 0) — masking with rate 0 changes nothing, so repeating it over 5 seeds would only duplicate rows.
- **Final-test lock is written before the evaluation starts**, keyed by checkpoint SHA-256 and run name, so even a crashed attempt counts. Re-running needs a deliberate, visible edit to `results/final_test_lock.csv`.
- **Evaluate takes experiment settings from the checkpoint** and only paths/runtime from the current config, so a Kaggle-trained checkpoint can be evaluated on a laptop without config drift.
- **XAI sweep runs on the validation split only** — NEEDS HUMAN REVIEW. Invariant 5 reserves the test split for `evaluate --final-test`; if the paper needs test-split faithfulness numbers, extend that one command rather than letting xai_eval read the test split.
- **Deletion baseline = 0 in normalised space (the ImageNet channel mean); insertion starts from a Gaussian-blurred copy** (kernel 31, sigma 10), following RISE. Target class = the model's prediction at that missingness rate. Random-order baseline uses a per-image seeded permutation.
- **FLOPs are reported as multiply-accumulates (GMACs) from fvcore** (thop fallback). EfficientNet-B0 at 224 px: 0.414 GMACs; the gated model adds ~0.43 M parameters and ~0.007 GMACs. Efficiency is architecture-only (pretrained=False), measured single-threaded at batch 1.
- **Resized image cache:** `prepare_data --cache-images` writes every image with its short side at 256 px to `data/processed/` (223 MB versus 3.6 GB raw; raw images are 476-1197 px squares). The loader prefers the cache when it exists. **Upload the cache (not the raw zips) as the Kaggle dataset**, and use the same cache everywhere, because resizing twice (raw->256->224) is not bit-identical to raw->224.
- **Real-data pipeline check (not a result):** a 3-step gated training run with pretrained ImageNet weights plus a 1-batch evaluation sweep ran end to end on the real images on CPU; outputs were written only to `tmp/pipeline_check/` (gitignored). No numbers from it are reported anywhere.
- **Review fixes (after docs pass):** config hash now also excludes `eval`, `xai`, `efficiency` (eval-only changes no longer rename a training run or block `--resume`); evaluation and XAI never apply `data.train_subset`, so the `all` subset really is all rows; bootstrap CIs now also cover every per-class recall (MEL CIs matter); real-data code paths refuse to regenerate a missing split file; `prepare_data` summarises the SAVED split file and warns if a recomputation would differ; the XAI sweep uses a seeded random sample of validation images (`xai.sample_seed`), identical across models; `--ckpt` accepts a quoted glob matching exactly one file.
- **Known, not changed:** the gate input includes the missingness ratio, which in PAD-UFES-20 correlates with "benign" (see the data finding). The gate can therefore partly encode the label shortcut; interpret `val_gate_mean_all_masked` together with the complete_metadata results. The playbook says masking should never happen "during training of the evaluated model"; this repo deliberately trains with random modality dropout (per the overnight brief) and keeps inference masks separate, keyed and fixed-rate — NEEDS HUMAN REVIEW against the playbook.

## 2026-10-12 — WP10 independent leak hunt (Opus subagent, saw only data.py, masking.py, models.py, tests)

No train/val/test leak was found in the shipped train/evaluate paths (it instrumented the pipeline: preprocessor fit on train rows only, class weights from train labels, vocab train-only, 0 patient/lesion/image/group overlap for seeds 42/0/1/2/3, no near-duplicate images across patients). What it did find, and what changed:

- **`UNK` is now a real category, not missing** (reverses the earlier entry) — NEEDS HUMAN REVIEW. "UNK" is the patient's answer "I don't know", and it leans malignant (P(grew=UNK | SCC) = 0.39, BCC 0.32, ACK 0.008), while a not-recorded questionnaire block is 100% benign. Merging both into index 0 gave index 0 opposite meanings per field and made masking grew/changed inject a malignant-leaning value. Now index 0 = not recorded (empty/NaN/NA/None, case-insensitive) or unseen-in-train; UNK gets its own learned embedding. This also reads invariant 2 more literally (missing must never equal "unknown-as-a-real-category"). Consequence: missingness_profile.csv now reports `n_unk_answer` separately; `complete_metadata` = 1,494 rows (BCC/MEL/SCC 100% complete, ACK 39%, NEV 31%, SEK 20%).
- **Default `eval.mask_pool` is now `observed`, and it hides `floor(r * n_observed + 0.5)` of each image's own observed fields** (reverses the earlier entry) — NEEDS HUMAN REVIEW. With `all`, a nominal 30% hid ~5.8 real fields on malignant rows but only ~3.0-3.7 on benign rows (draws landed on already-missing benign fields), so the sweep's x-axis was confounded with class. `all` is still available.
- **Test-split guard is strict:** `load_split(..., allow_test=...)` now requires `allow_test is True`; the string "False" used to pass the truthiness check. (Split *creation* — `patient_level_split`, `split_to_frame` — necessarily knows the test rows; the guard is on the loading path every consumer uses.)
- **Overlap checks raise `LeakError`** (an AssertionError subclass) explicitly instead of bare `assert`, so `python -O` cannot disable them; a missing identity column is now an error, not silently skipped; `load_split` returns positional indices (correct on any DataFrame index).
- **Categorical spellings are canonicalised** ('2' == '2.0', 'True' == 'TRUE', surrounding spaces ignored) and continuous values that are non-finite or overflow float32 are treated as missing (an age of '1e40' used to become inf and turn gate=0 outputs into NaN).
- **Gate-zero test strengthened:** BatchNorm is calibrated first (uncalibrated, the logits varied by only ~2e-6 across images, a 6x margin over the 1e-6 tolerance), image-sensitivity is asserted, a blank-image control and an exact g=0.5 check against `head(glob + 0.5*attn)` were added. Mutation check: a gate floor `(g+1e-4)*attn`, `(1-g)*glob + g*attn` and `glob*(1+g) + g*attn` are all now caught (all passed the old test).
- **Dataset facts it quantified (for the paper):** P(malignant | questionnaire block empty) = 0.000 vs 0.729 otherwise; 102 of the 345 test images (29.6%) have the block empty, all benign; the gate's `missingness_ratio` input is >= 0.3 exactly when the block is empty, so it separates these rows perfectly; training-time modality dropout reproduces that 13-field pattern with probability ~6e-5 per sample, so it does not break the shortcut; missingness flags alone reach logistic balanced accuracy 0.374 (chance 0.167). **Label noise:** 15 byte-identical image pairs (same patient, different lesion ids), 12 with conflicting diagnoses; 226 lesion ids carry more than one diagnosis. None of these cross splits (same patient => same group).
